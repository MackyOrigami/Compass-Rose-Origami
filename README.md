# Compass Rose — Original Origami Design

An original origami sculpture designed by **Mackenzie Bruce**, created October 18, 2026.

## The Design

An experiment of the frog body: a classic frog base transformed by bulking out the frog's body and valley folding down around the center point to create the center piece — a hexagon with 6 points — with the 4 flaps shaped into pleated starburst arms radiating outward.

Folded from a single square with no cuts and no glue. Clean, geometric, and sharp from every angle.

**Note:** This is a sculpted one-of-a-kind piece, not a step-by-step guide. This repository serves as its public documentation and publication record.
